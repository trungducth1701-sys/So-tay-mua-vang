In nhãn gửi thư

Tải file Excel lên, gõ ngày cần lấy, bấm tạo. Ra một file Word nhãn dán, mỗi ô là một đơn vị.

1 Tải file Excel
Bấm để chọn file hoặc kéo thả vào đây
Hỗ trợ .xlsb, .xlsx, .xls. File chỉ được xử lý ngay trên máy bạn, không gửi đi đâu.
2 Nhập ngày cần lấy
3 Kiểm tra thông tin

Mỗi đơn vị một ô nhãn (2 cột × 3 hàng, 6 ô một trang, nhiều hơn 6 thì sang trang sau). Sửa trực tiếp nếu cần, bỏ tích đơn vị nào thì không in đơn vị đó.
